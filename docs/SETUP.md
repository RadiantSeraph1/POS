# Setup

## Local Requirements

- Node.js LTS
- pnpm
- PostgreSQL
- Redis
- Optional Docker Desktop

## First-Time Steps

1. Install dependencies with `pnpm install`.
2. Copy `.env.example` to `.env`.
3. Start PostgreSQL and Redis.
4. Run package typechecks with `pnpm typecheck`.
5. Start placeholder apps with `pnpm dev`.

## Notes

This repo is currently a scaffold. Full NestJS, Electron, database schema, and sync implementation are still pending.
